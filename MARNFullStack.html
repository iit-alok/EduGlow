2. Node.js Runtime & Non-Blocking Event Loop

Node.js runs on Google Chrome's V8 JavaScript Engine and uses a single-threaded event loop with libuv to handle thousands of concurrent operations without thread blocking.

Understanding the Phases of the Event Loop:
  1. Timers Phase: Executes callbacks scheduled by setTimeout() and setInterval().
  2. I/O Callbacks: Executes deferred callbacks (network errors, system operations).
  3. Poll Phase: Retrieves new I/O events; blocks here when waiting for incoming socket connections.
  4. Check Phase: Executes setImmediate() callbacks right after the poll phase finishes.
  5. Close Callbacks: Cleanups (e.g. socket.on('close', ...)).

3. Express.js REST APIs & Middleware Chain

Express operates as a pipeline of Middleware functions that intercept incoming request (req) and response (res) objects before reaching controllers. 

// server.js - Production-ready Express Boilerplate
import express from 'express';
import cors from 'cors';

const app = express();

// Essential Global Middleware
app.use(cors());
app.use(express.json()); // Parses application/json body

// Sample REST Route
app.get('/api/health', (req, res) => {
    res.status(200).json({ status: 'Active', author: 'Alok Rajpoot' });
});

// Central Error Handler Middleware
app.use((err, req, res, next) => {
    const statusCode = err.statusCode || 500;
    res.status(statusCode).json({ error: err.message || 'Internal Server Error' });
});

app.listen(5000, () => console.log('API Server running on port 5000'));

4. MongoDB & Mongoose Schema Modeling

Mongoose acts as an Object Data Modeling (ODM) layer providing strictly-typed schemas, validations, and hooks on top of unstructured MongoDB documents. 

// models/Note.js - Schema Definition with Validation
import mongoose from 'mongoose';

const noteSchema = new mongoose.Schema({
    title: { 
        type: String, 
        required: [true, 'Title is mandatory'], 
        trim: true 
    },
    category: { 
        type: String, 
        enum: ['backend', 'fullstack', 'scripting', 'core'],
        default: 'fullstack'
    },
    author: { 
        type: mongoose.Schema.Types.ObjectId, 
        ref: 'User',
        required: true
    }
}, { timestamps: true });

// Compound Index for lightning-fast queries
noteSchema.index({ category: 1, createdAt: -1 });

export default mongoose.model('Note', noteSchema);

5. Modern React Architecture & Core Hooks

React builds dynamic interfaces using composable components. Data flows downwards via props, and events flow upwards via callbacks.

useState & useEffect

useState holds reactive component state; useEffect synchronizes side-effects (API calls, subscriptions, DOM mutations).

useContext & useReducer

Replaces prop-drilling by providing an application-wide state pipeline for authenticated user data and themes.

Real Component Implementation:
// components/NotesList.jsx
import React, { useState, useEffect } from 'react';
import axios from 'axios';

export default function NotesList() {
    const [notes, setNotes] = useState([]);
    const [loading, setLoading] = useState(true);

    useEffect(() => {
        const fetchNotes = async () => {
            try {
                const { data } = await axios.get('/api/notes');
                setNotes(data);
            } catch (err) {
                console.error('Failed to fetch:', err);
            } finally {
                setLoading(false);
            }
        };
        fetchNotes();
    }, []); // Empty dependency array runs once on mount

    if (loading) return <p>Loading EduGlow Notes...</p>;

    return (
        <div className="notes-container">
            {notes.map(n => <h5 key={n._id}>{n.title}</h5>)}
        </div>
    );
}

6. End-to-End JWT Authentication Pipeline

JSON Web Tokens (JWT) enable stateless user authorization. The server issues a cryptographically signed token containing claims upon user login. 

// middleware/authMiddleware.js - Express JWT Verification
import jwt from 'jsonwebtoken';

export const protect = (req, res, next) => {
    const authHeader = req.headers.authorization;

    if (authHeader && authHeader.startsWith('Bearer ')) {
        try {
            const token = authHeader.split(' ')[1];
            const decoded = jwt.verify(token, process.env.JWT_SECRET);
            req.user = decoded; // Attach payload to request object
            return next();
        } catch (error) {
            return res.status(401).json({ message: 'Token expired or invalid' });
        }
    }
    res.status(401).json({ message: 'Not authorized, no token provided' });
};

7. Production Deployment & Interview Best Practices

Deployment Checklist:
  • Environment Variables: Store secrets, Database URIs, and JWT keys in .env files; never commit them to Git.
  • CORS Configuration: Whitelist only your production frontend domain (e.g. origin: 'https://eduglow.in').
  • Hosting Strategy: Deploy MongoDB on MongoDB Atlas, Express API on Render/Railway/AWS EC2, and React on Vercel/Netlify.
Key Interview Question: How does React's Virtual DOM work?

React maintains an in-memory representation of the real DOM. When state changes, a new Virtual DOM tree is created and compared against the previous one using the Reconciliation (Diffing) Algorithm. Only the changed nodes are updated in the actual browser DOM, reducing expensive paint operations.
