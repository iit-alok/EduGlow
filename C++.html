1. Pointers, References & Dynamic Memory Allocation

C++ provides manual memory control. Variables allocated on the Stack are cleared automatically upon scope exit, while memory on the Heap allocated via new must be explicitly reclaimed using delete to prevent memory leaks [source: 3, 4].

Feature Pointer (int* ptr) Reference (int& ref)
Reassignment Can point to different memory addresses [source: 4, 5]. Bound permanently to its initialized variable [source: 4, 5].
Nullability Can be nullptr [source: 4]. Must bind to a valid object upon declaration.
Memory Allocation Heap allocation via new int[N] [source: 3, 4]. Alias of an existing variable; no separate storage. 
// Dynamic memory allocation and safe cleanup in C++
int* arr = new int[5]; // Allocated in Heap memory [source: 3, 4]

for (int i = 0; i < 5; i++) {
    arr[i] = (i + 1) * 10;
}

delete[] arr;  // Essential: Reclaiming memory to prevent leaks [source: 3, 4]
arr = nullptr; // Avoid dangling pointer

3. C++ Standard Template Library (STL)

The STL provides pre-built, template-based data structures and algorithms optimized for execution speed [source: 1, 3]. 

#include <iostream>
#include <vector>
#include <unordered_map>
#include <algorithm>

int main() {
    // 1. Dynamic Vector [source: 1]
    std::vector<int> vec = {40, 10, 30, 20};
    std::sort(vec.begin(), vec.end()); // O(n log n) Introsort [source: 1, 6]

    // 2. Hash Map for O(1) Average Lookup [source: 1]
    std::unordered_map<std::string, int> marks;
    marks["Alok"] = 98;
    marks["Rahul"] = 89;

    if (marks.find("Alok") != marks.end()) {
        std::cout << "Score: " << marks["Alok"] << std::endl;
    }
    return 0;
}

4. Linked List Data Structures

Linked lists store elements in contiguous or non-contiguous nodes linked together via pointer references [source: 1, 4]. 

struct Node {
    int data;
    Node* next;
    Node(int val) : data(val), next(nullptr) {}
};

// Reversing a Singly Linked List in O(n) Time, O(1) Space [source: 1, 4]
Node* reverseList(Node* head) {
    Node* prev = nullptr;
    Node* curr = head;
    while (curr != nullptr) {
        Node* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}

5. Binary Search Trees & Priority Heaps

Non-linear hierarchical data structures reduce search complexity from $\mathcal{O}(n)$ to $\mathcal{O}(\log n)$ [source: 1, 4].

Binary Search Tree (BST)

For every node $X$, all keys in the left subtree are smaller ($< X$) and all keys in the right subtree are larger ($> X$) [source: 4, 7].

Max Heap / Min Heap

Complete binary tree where the parent node is strictly greater (or smaller) than its child nodes. Implemented in STL via std::priority_queue [source: 1, 4].

6. Graph Algorithms: BFS & DFS

A Graph consists of vertices $V$ and edges $E$ [source: 4, 9]. Represented using an Adjacency List for optimal $\mathcal{O}(V + E)$ space complexity [source: 4, 5]. 

#include <vector>
#include <queue>

// Breadth-First Search (BFS) Traversal [source: 4]
void bfs(int startNode, const std::vector<std::vector<int>>& adj, int V) {
    std::vector<bool> visited(V, false);
    std::queue<int> q;

    visited[startNode] = true;
    q.push(startNode);

    while (!q.empty()) {
        int node = q.front();
        q.pop();

        for (int neighbor : adj[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}

QuickSort operates in-place with $\mathcal{O}(1)$ auxiliary space complexity (aside from recursion stack frames) and exhibits strong cache locality [source: 6]. In contrast, MergeSort requires $\mathcal{O}(n)$ additional heap space for temp allocations, making it slower on standard array architectures [source: 6].

If a derived class object is deleted through a pointer to the base class without a virtual destructor, it causes undefined behavior. Only the base class destructor will execute, leading to resource and memory leaks for any dynamic fields owned by the derived class [source: 4].
