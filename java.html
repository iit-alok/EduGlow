Part 1: Foundations

1. Introduction to Java & JVM Architecture

Java is an object-oriented, class-based, high-level programming language developed by Sun Microsystems in 1995. Its defining architectural trait is "Write Once, Run Anywhere" (WORA).

Figure 1: Java Source Code (.java) to Bytecode (.class) compilation and JVM execution.
JDK vs JRE vs JVM:
  • JDK (Java Development Kit): Everything needed for software engineering—compiler (javac), debuggers, tools, and the JRE.
  • JRE (Java Runtime Environment): The minimum runtime engine containing class libraries (rt.jar) to execute pre-compiled code.
  • JVM (Java Virtual Machine): Loads, verifies, and executes platform-independent bytecode via the ClassLoader, JIT compiler, and Garbage Collector.

4. Classes, Objects & Constructors

A Class is a blueprint or template, while an Object is a real-world instance that occupies memory in the Heap.

Class Members

Composed of fields (state), methods (behavior), and constructors (instantiation routines).

Constructors & `this`

Special methods invoked upon object creation with new. The this keyword disambiguates instance fields from local parameters.

5. The Four Core Pillars of OOPS

The foundation of Object-Oriented design is built on four central mechanisms:

1. Encapsulation

Bundling state with behavior while restricting unauthorized direct access via private variables and public getters/setters.

2. Abstraction

Exposing essential contracts while hiding low-level implementation details through interfaces and abstract classes.

3. Inheritance

Deriving new classes from existing classes using extends to promote code reuse and establish 'IS-A' hierarchies.

4. Polymorphism

Enabling methods to take multiple forms through Method Overloading (Compile-Time) and Method Overriding (Run-Time).

Working OOP Code Walkthrough:
// 1. Encapsulation & Inheritance in practice
class Student {
    private String name; // Encapsulated state

    public Student(String name) {
        this.name = name;
    }

    public String getName() {
        return this.name;
    }

    public void study() {
        System.out.println(name + " is studying core fundamentals.");
    }
}

// Polymorphism: Overriding inherited behavior
class EngineeringStudent extends Student {
    public EngineeringStudent(String name) {
        super(name);
    }

    @Override
    public void study() {
        System.out.println(getName() + " is mastering Java, Spring Boot & DSA!");
    }
}

7. Exception Handling & Try-With-Resources

Exceptions in Java represent runtime error events. Robust programs catch anomalies defensively without leaking sockets or files. 

import java.io.*;

public class SafeFileIO {
    // Try-With-Resources automatically closes AutoCloseable streams
    public static void readFile(String filePath) {
        try (BufferedReader br = new BufferedReader(new FileReader(filePath))) {
            System.out.println(br.readLine());
        } catch (IOException e) {
            System.err.println("Diagnostic Trace: " + e.getMessage());
        }
    }
}

9. Multithreading & Concurrency Management

Multithreading enables concurrent execution of instructions, taking full advantage of modern multi-core processors. 

import java.util.concurrent.*;

public class ConcurrencyDemo {
    public static void main(String[] args) {
        // Utilize ExecutorService pools instead of instantiating raw threads
        ExecutorService pool = Executors.newFixedThreadPool(2);

        pool.execute(() -> {
            System.out.println("Executing asynchronously on: " + Thread.currentThread().getName());
        });

        pool.shutdown();
    }
}

10. Java 8+ Lambdas, Functional Interfaces & Streams

Functional programming in Java allows for declarative data transformations without manual loop management. 

import java.util.*;
import java.util.stream.Collectors;

public class StreamsDemo {
    public static void main(String[] args) {
        List<String> studentRoster = Arrays.asList("Alok", "Ankit", "Rahul", "Amit");

        // Filter, transform and collect in a declarative pipeline
        List<String> filteredList = studentRoster.stream()
            .filter(name -> name.startsWith("A"))
            .map(String::toUpperCase)
            .collect(Collectors.toList());

        System.out.println(filteredList); // [ALOK, ANKIT, AMIT]
    }
}
